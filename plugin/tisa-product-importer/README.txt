Tisa Product ZIP Importer

This plugin is built from plugin/tisa-product-importer.php in the TisaPostToWP
repository. Run `python scripts/build_plugin_zip.py` there after editing the PHP,
and upload the resulting tisa-product-importer.zip.

Installation:
1. Upload tisa-product-importer.zip (WordPress > Plugins > Add New > Upload).
2. Activate it from WordPress Plugins.
3. Make sure WooCommerce is active.
4. Go to WooCommerce > ورود محصول تیساکیس.
5. Upload product.zip generated by the Telegram bot.

The importer creates a draft variable product, leaves description empty,
creates the combinations of product attributes, uses one SKU on the parent
product, and finds the next numeric SKU for the supplied prefix.

Per-model colors: when product.json carries "model_colors" (model -> the colors
in stock for it), the color attribute still lists EVERY color, but only the
listed model/color pairs become variations. Models missing from that map stay
unrestricted, and a model whose colors match none of the real color options is
left unrestricted too, so no sellable variation is ever dropped.
