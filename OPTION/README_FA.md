# Tisa iPhone Telegram Bot — Smart Local Parser

این نسخه برای پست‌های واقعی و نامرتب فروشگاهی طراحی شده و به‌صورت **Local + Long Polling** اجرا می‌شود.

## منطق تشخیص

ربات متن را صرفاً با جستجوی چند کلمه پردازش نمی‌کند؛ از ساختار پست و عنوان بخش‌ها هم استفاده می‌کند.

### iPhone

موارد زیر استاندارد می‌شوند:

- `iphone 17promax` → `iPhone 17 Pro Max`
- `iphone 14Pro` → `iPhone 14 Pro`
- `iphone Xsmax` → `iPhone XS Max`
- `iphone 7+/8+` → `iPhone 7 Plus/8 Plus`
- `iphone 7/8` → `iPhone 7/8`

گروه‌های slash یک **آیتم واحد** باقی می‌مانند و به دو مدل جدا تبدیل نمی‌شوند.

### Samsung

پیشوند `Samsung` در خروجی حذف می‌شود:

- `S25 ultra` → `S25 Ultra`
- `S25 fe` → `S25 FE`
- `A21 s` → `A21s`  ← عمداً هرگز به `A21` تبدیل نمی‌شود
- `A32 4G` → `A32 4G`

### Xiaomi / Redmi

پیشوند عمومی `Xiaomi` از خروجی حذف می‌شود، اما `Redmi` چون بخشی معنادار از نام مدل است حفظ می‌شود:

- `Xiaomi / Note12 4G` → `Note 12 4G`
- `Redmi Note12 4G` → `Redmi Note 12 4G`
- `Note 13 pro plus` → `Note 13 Pro Plus`

بنابراین `Redmi Note 12 4G` هیچ‌وقت به `Note 12 4G` تبدیل نمی‌شود، وقتی `Redmi` در ورودی وجود دارد.

## خروجی

مدل‌ها با ` | ` جدا می‌شوند، تکراری‌ها حذف می‌شوند و به ترتیب طبیعی برند/مدل مرتب می‌شوند.

## چرا فعلاً AI اجباری نشده؟

برای ورودی‌های شناخته‌شده، parser قطعی بهتر است چون خروجی آن deterministic است و مدل AI ممکن است بعضی suffixها، برندها یا گروه‌های سازگاری را تغییر دهد. ساختار پروژه طوری نوشته شده که بعداً می‌توان **AI fallback** را فقط برای مدل‌های ناشناخته اضافه کرد؛ یعنی AI جای parser دقیق را نمی‌گیرد.

## اجرا

1. فایل `.env.example` را به `.env` تبدیل کنید.
2. `BOT_TOKEN` و `OWNER_USER_ID` را تنظیم کنید.
3. `start_bot.bat` را اجرا کنید.

ربات فقط برای User IDهای موجود در `OWNER_USER_ID` پاسخ می‌دهد.

می‌توانید چند User ID وارد کنید و آن‌ها را با `,` یا `;` یا فاصله جدا کنید؛ مثلاً:
`OWNER_USER_ID=123456789,987654321,555555555`

## تست

تست‌های نمونه واقعی داخل `tests/test_parser.py` قرار دارند. نسخه فعلی: **5/5 تست موفق**.

## AI mode

برای فعال کردن AI این سه مقدار را در `.env` قرار بده:

```env
AI_BASE_URL=https://api.openai.com/v1
AI_TOKEN=YOUR_TOKEN
AI_MODEL=YOUR_MODEL_NAME
```

ربات از endpoint سازگار با OpenAI در مسیر `/chat/completions` استفاده می‌کند. AI نقش استانداردسازی و validation را دارد و اگر API در دسترس نباشد، ربات با parser قطعی ادامه می‌دهد.

## Status / Error Log

برای هر job یک پیام وضعیت ساخته می‌شود و مراحل روی همان پیام update می‌شوند:

`📥 دریافت شد` → `📦 دانلود` → `🔎 استخراج مدل` → `🤖 AI` → `🛡️ اعتبارسنجی` → `📤 آپلود` → `✅ انجام شد`

اگر خطایی رخ بدهد، پیام خطا و یک فایل `error_log.txt` شامل traceback و لاگ همان job برای Owner ارسال می‌شود.


## فشرده‌سازی تصویر
عکس‌ها قبل از ارسال دوباره به JPG با کیفیت بالا encode می‌شوند. فرمت خروجی JPG باقی می‌ماند و ابعاد تصویر تغییر نمی‌کند. مقدار `IMAGE_QUALITY=88` قابل تنظیم است.
